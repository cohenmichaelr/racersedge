# Project: The Racer's Edge Modernization 🚴‍♂️

## Project Context
- **Business:** High-end bike shop in Boca Raton, FL.
- **Vibe:** Clean, premium, athletic.
- **Tech Stack:** HTML5, Tailwind CSS.

## Development Rules
- **Styling:** Always use Tailwind CSS utility classes. 
- **Design:** Dark mode with "Electric Blue" (#007FFF) accents.
- **Mobile First:** All layouts must be optimized for cyclists on mobile.

## Definition of Done (DoD)
- Code must be documented with "Why" comments.
- Layouts must be responsive.
